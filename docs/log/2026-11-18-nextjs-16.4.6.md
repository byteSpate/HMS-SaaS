# Chore: Next.js 16.4.6 and the T-CLI-03 Supabase migrations

- **Date:** 2026-11-18
- **Commit:** this commit
- **Implements:** dependency security floor (D1 section 4, docs/STACK_VERSIONS.md); DEPLOYMENT.md section 4 record

## What was built

`apps/web` and `apps/site` move from Next.js 16.4.3 to 16.4.6. `pnpm audit --prod` reported two moderate advisories for 16.2.0 to 16.4.4: information disclosure and a cache leak across root params with `use cache`. Both are fixed from 16.4.5; 16.4.6 is the newest 16.4 patch. The dev server also showed this warning at start-up.

Riding along: the two T-CLI-03 migrations were applied to Supabase after PR #59 merged, and the DEPLOYMENT.md section 4 row and the two T-CLI-03 logs now say so.

## Decisions applied

- **A patch within 16.4,** not a minor upgrade: the smallest change that clears the advisories, so no code changes are needed.
- **16.4.6 rather than 16.4.5:** released 2026-11-09, nine days before this change, so it passes pnpm's minimum release age check.

## Known limitations

- `main` and staging still run Next.js 16.4.3 until the next release.

Deploy impact: web and site images rebuild with Next.js 16.4.6 on the next release. No variable, migration or origin change.

## How to debug

A build or runtime difference after the upgrade: compare against 16.4.3 by pinning it back in both `package.json` files and running `pnpm install`. The release notes are on the Next.js GitHub releases page.
