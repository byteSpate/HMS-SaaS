# CMS demo surface

Mode: Operate. Hospital staff explore an editor with fictional content; no real account or hospital information is involved. Existing PRODUCT.md and DESIGN.md describe the visual system; C-089 and C-092 supersede their historical shared SaaS and real-data assumptions for this surface.

## Direction contract

THESIS: Make draft, preview and publication understandable through a working local demonstration. Ready-made sections remain the unit of composition.

OWN-WORLD: Extend the existing clinical teal, neutral surfaces, shared UI fonts and in-house components. Use AppShell and PageLayout for desktop, tablet and phone behavior.

STORY: The visitor edits fictional bilingual content, saves it, compares draft with published demo content, restores an earlier version and resets the browser demo.

FIRST VIEWPORT: Shared navigation, language control, page title and clear demo notice precede a command bar. The selected page and section list occupy the main work area. Publish remains disabled until a valid draft is saved.

FORM: Established-system extension; no concept seed or replacement visual world. The signature interaction is the separation between the saved draft preview and the published demo preview. Motion is limited to existing shared control feedback.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No new raster assets or design tokens are introduced. Images are existing fictional CareSpate assets. Media upload, collection editors and production authentication are outside this first demo slice.
